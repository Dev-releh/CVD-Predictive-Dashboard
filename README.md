Predictive Analytics Dashboard – CVD Risk Detection (Research Prototype)

📌 Project Overview
A research prototype for a predictive analytics dashboard designed to support early cardiovascular disease (CVD) risk detection in South African public hospitals. The project aimed to bridge the gap between machine learning models and practical clinical implementation. Completed as part of a Research Module at Central University of Technology.

📊 Key Highlights
🖼️ High-fidelity Figma prototype designed
📊 Quantitative analysis of cardiovascular datasets conducted
📋 User requirements gathered via questionnaires
🧩 Use case diagrams, ERD, and system architecture created
📄 Comprehensive research report produced

🗂️ Dataset Used
The analysis used the Heart Disease Classification Dataset from Kaggle. The dataset contains 1319 patient samples with nine fields. Eight fields are inputs: age, gender (0 for female and 1 for male), heart rate (impluse), systolic blood pressure (pressurehight), diastolic blood pressure (pressurelow), blood sugar (glucose), CK-MB (kcm) and test troponin (troponin). The ninth field is the output which is the presence of a heart attack (class). The class has two categories. Negative means no heart attack and positive means a heart attack. The data supports early detection work because it holds the clinical factors that contribute to a heart attack. Link:[Heart Disease Dataset](https://www.kaggle.com/datasets/bharath011/heart-disease-classification-dataset)
